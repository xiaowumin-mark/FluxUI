# Form Validation Example

This example intentionally remains a legacy `Run` / `Widget` example during the React-style docs rollout.

It exercises complex input behavior with `TextField`, validation state, controlled values, and command-style updates. Batch 4 keeps it as a compatibility reference until the host-state and ref boundary for complex inputs is finalized.

Do not rewrite this example to `RunElement` until APIs such as `TextFieldElement`, `SelectElement`, `RadioGroupElement`, or `SliderElement` have a stable host-state strategy.
